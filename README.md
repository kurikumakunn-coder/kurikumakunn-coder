# ゆにゃち ウマガールダービー（試作版）

配信の参加を競走馬の成長につなげる、オリジナルのブラウザゲームです。
アプリ本体は **`index.html` の1ファイル**です。外部ライブラリ・画像・API・ビルドは不要です。

## 遊ぶ

1. `index.html` をブラウザで開きます。
2. 「牧場・育成」で応援する馬を選びます。
3. 配信者が参加・達成を確認し、「草」「クイズ正解」「応援企画達成」「BINGO」「指定アイテム」のボタンを押します。
4. 「レース」からスタート。約16〜22秒のレース後、着順と戦績が保存されます。
5. 「また育てる」で牧場に戻り、育成とレースを繰り返します。

BINGOは「選択中の馬」「全馬に」を切り替えられます。
「管理モード」では、改名・能力修正・EXP追加・脚質変更・タイトルとレース名変更ができます。
初期レース名は「初星ダービー」です。

ミクチャとの自動連携はありません。配信者が馬単位で操作するサンプルです。
コメント数やリスナー個人の課金額は集計しません。

ブラウザがローカルファイルの保存を制限する場合は、Pythonの簡易サーバーを使えます。

```sh
cd /workspace/kurikumakunn-coder
python -m http.server 8000
```

その場合はブラウザで `http://localhost:8000` を開きます。

## データ保存

- 操作後は `localStorage` に自動保存します。保存できない場合は画面に表示します。
- 馬の名前を変えても、`horse-01` などの固定IDで育成・戦績を引き継ぎます。
- 過去のレースには出走時の馬名・脚質を記録します。改名後も当時の名前が残ります。
- 保存場所はブラウザ・端末・アクセス元ごとに異なります。ファイルを移動したり、ローカルファイルからHTTPに切り替える前にはバックアップを書き出してください。
- 管理モードでJSONの書き出し・読み込みができます。読み込みと初期化には確認画面があります。
- レース途中でページを閉じた場合、そのレースは未完了として戦績に加算しません。
- 管理モードは操作画面の切り替えです。認証や閲覧者の操作制限はありません。

## 後から変更する

`index.html` 冒頭の **`CONFIG`** に設定をまとめています。日本語コメントも参照してください。

| 変更内容 | 設定 |
| --- | --- |
| ゲーム名・案内文 | `title` / `text` |
| シーズン表示 | `seasonName` |
| 馬名・脚質・毛色・初期能力・配色 | `horses` |
| 馬の追加 | `horses` に、重複しない新しい `id` の行を追加 |
| 育成方法・獲得ポイント | `actions` の `gains` |
| レース名・距離・時間 | `race` |
| レベルアップに必要なEXP | `levelExp` |
| オリジナルの馬画像 | 各馬に `image: '画像ファイルのパス'` を追加 |

**運用開始後は馬の `id` と `storageKey` を変えないでください。**
既存セーブの馬名・能力はセーブ側を優先します。現在育てている馬を変更する場合は管理モードを使い、初期値を試し直す場合はバックアップ後に初期化してください。
馬を追加すると、既存データを引き継ぎながら新しい馬が初期状態で加わります。

## レースの仕組み

`buildRacePlan()` が能力・脚質・調子・区間ごとの展開をもとに、各馬の進捗と入線時刻を計算します。
`requestAnimationFrame` でその進捗を描画し、同じ入線時刻で順位を決めるため、見た目と結果が一致します。

スピードは速度、スタミナは終盤の維持、根性は接戦の粘り、賢さは安定性に影響します。
能力の効果は逓減し、レース上の有効能力は200で上限になります。保存できる能力値は0〜999です。
逃げは序盤、差し・追込は後半に伸びます。高い能力や指定アイテムによる成長が勝利を保証する仕組みにはしていません。

この試作版のレベルは累計EXPから計算します。能力の自動上乗せはなく、能力は育成ボタンと管理モードで成長します。
シーズンの自動切り替え・配信API・オンライン共有は、今後追加する想定です。
